# PROJECT: Enterprise Agentic AI Company Website
## Mission
Build and maintain a premium enterprise Agentic AI technology website.
This is not a template website.
It must feel like a serious technology product company.
## Engineering Principles
1. TypeScript strict mode.
2. Prefer Server Components.
3. Use Client Components only when necessary.
4. Components must be reusable.
5. Avoid duplicated code.
6. Never expose secrets.
7. Never hardcode API keys.
8. Keep AI provider integrations abstracted.
9. Optimize for performance.
10. Accessibility is mandatory.
11. SEO is mandatory.
12. Mobile-first design.
13. Avoid unnecessary dependencies.
14. Never introduce a library just to solve a trivial problem.
15. Run lint and build before completing significant work.
## Design Principles
The design must be:
Premium
Technical
Enterprise
Minimal
Confident
Modern
Avoid:
Generic AI imagery
Stock photography
Excessive gradients
Excessive glassmorphism
Generic SaaS templates
Over-animation
Fake statistics
Fake testimonials
## Content Principles
Never invent:
Customers
Statistics
Certifications
Partnerships
Awards
Testimonials
Case studies
Use placeholders where real information is unavailable.
## Motion
Motion should communicate:
Flow
Execution
Orchestration
Relationships
Hierarchy
Motion must never exist only for decoration.
Respect:
prefers-reduced-motion.
## Architecture
Prefer:
Next.js App Router
TypeScript
Tailwind
Reusable components
Server Components
Static generation where possible
Vercel deployment
## AI
The website should remain model-provider agnostic.
Potential providers:
Gemini
OpenAI
Anthropic
Open-source models
AI API calls must occur server-side.
Never expose API keys in client code.
## Future Compatibility
Architecture must allow future additions:
Customer authentication
AI agent demos
Agent dashboards
Customer portals
Billing
Analytics
Documentation
AI APIs
MCP integrations
Knowledge bases
Do not design the marketing site in a way that prevents these future additions.
## Quality Standard
Before considering work complete:
* TypeScript passes
* ESLint passes
* Build passes
* Responsive behavior verified
* Accessibility reviewed
* SEO reviewed
* No console errors
* No broken links
* No missing assets
* No exposed secrets
The final result must look human-designed and enterprise-grade.
